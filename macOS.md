## asahi linux installation
download [asahi linux with a Plasma KDE](https://asahilinux.org/)

## installation
1. open **Terminal**\
`curl https://alx.sh | sh`
	**n**: expert mode\
	**r**: resize\
	**80 gb**: new size\
	**y**: continue\
	**f**: install\
	**1**: asahi linux desktop\
	**max**: new OS size
3. hold down **Power** button to restart
4. select **Asahi Linux**\
	**y**: custom boot object

## optional
- option to install utm\
[Ubuntu Install on M1 MacBook Air - Virtualization and Benchmarking!](https://youtu.be/hnwK-nkXolc)

- utm settings
1. download [UTM Virtual Machines](https://apps.apple.com/us/app/utm-virtual-machines/id1538878817?mt=12)
2. select **Create a New Virtual Machine**
3. `Information\Style`
4. set **Operating System**
5. `System\Architecture`
6. set **ARM64 (aarch64)**
7. set **Base Memory**
8. `Drivers\Interface\New Drive`
9. select **NVMe**
10. select **USB**
>Removable
